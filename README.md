Этот проект был реализован для изучения регрессии на табличных данных. Идея простая - есть данные с аукционов (художник, техника, размер холста, год написания, где и когда продали) и хочется предсказать цену в долларах. Сами данные синтетические, они были сгенирированы мной, потому что датасет с Christie's скачать не получилось, но логика та же - известные художники стоят дороже, масло дороже акварели, большие картины дороже маленьких.

В качестве модели взяла RandomForestRegressor, потому что он почти не требует подготовки и хорошо использует категориальные возможности после кодирования. В preprocess.py есть label encoding для художников и one-hot для техники, еще я добавила несколько своих идей: площади и возраста картины на момент продажи. Запускается через `python main.py`, в exploration.ipynb есть EDA с графиками. Если хочется предсказать цену для своей картины — функция predict_price в src/predict.py.
