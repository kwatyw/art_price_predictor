# Art Price Predictor

Этот проект я делал, чтобы потренироваться в регрессии на табличных данных. Идея простая — есть данные с аукционов (художник, техника, размер холста, год написания, где и когда продали) и хочется предсказать цену в долларах. Сами данные синтетические, я их сгенерировал сам, потому что нормальный датасет с Christie's скачать не получилось, но логика та же — известные художники стоят дороже, масло дороже акварели, большие картины дороже маленьких.

В качестве модели взял RandomForestRegressor, потому что он почти не требует подготовки и хорошо ест категориальные фичи после кодирования. В preprocess.py есть label encoding для художников и one-hot для техники, плюс я добавил пару своих фич типа площади и возраста картины на момент продажи. Запускается через `python main.py`, в exploration.ipynb есть EDA с графиками. Если хочется предсказать цену для своей картины — функция predict_price в src/predict.py.
